# Media assets — placeholders & replacement spec

All visuals currently on the site are **self-made placeholders** (procedural canvas / inline SVG). Replace them with real, publishable assets before launch. Videos: provide **WebM (VP9) + MP4 (H.264)**, muted, with a poster frame in `posters/`.
